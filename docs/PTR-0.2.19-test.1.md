# PTR 0.2.19 — Spell Icon Repair

- Fixed missing icon textures affecting Dominate Undead mastery controls, including Raise Undead, Dismiss Undead, and Revive Undead. The affected tester confirmed the repair works.
- Included 83 missing spell-icon textures, covering the same dependency issue in demon and dragonkin controls and other abilities.
- New and stock-client installations now receive these icons through the launcher instead of depending on an older local patch.

Close WoW, open the launcher, and update PTR to **0.2.19-test.1**. If you already installed that version, no further download is needed.

This is a client-only repair. No spell mechanics, character progression, or server restart changes are included. No replacement launcher ZIP is required.
