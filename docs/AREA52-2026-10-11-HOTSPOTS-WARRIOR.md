## Area 52 — Hotspot Maps and Warrior Proc Repairs

**Close the game, close and reopen the Bear Cave Launcher, and press Play to install the matching client update before testing.**

### XP Hotspots
- Hotspots now use geographic area names instead of quest-target names.
- Added more precise quest-area boundaries and substantially expanded Barrens coverage.
- Removed duplicate and holiday-focused seed locations from the rotation catalog.
- GMs can create and edit hotspot boundaries directly on the map and combine selected areas while preserving their actual coverage.
- Both hotspot map menus now use Bear Cave dark-blue styling with gold borders.
- Repaired the search field border and added search-as-you-type behavior.

### Sword and Board / Sword and Thunder
- Shield Slam only attempts its magic dispel while empowered by Sword and Board.
- Sword and Thunder redirects the proc to Thunder Clap: cooldown reset, no rage cost, and 20% bonus threat.
- Empowered Thunder Clap attempts to dispel one beneficial magic effect from the selected target only, provided that target is hit. Other targets are not dispelled.
- Equipping or removing Sword and Thunder clears an existing proc so its prior spell modifiers cannot linger.
- Updated the Sword and Thunder tooltip to describe these effects.
