# Area 52 — XP Hotspot Drawing Tools

Close the game, reopen the Bear Cave Launcher, and press **Play** to install the matching update.

- **Brush / fill:** CTRL-drag with an adjustable round or square brush to expand a polygon. Start on or overlapping its current boundary.
- **Trace perimeter:** CTRL-drag to draw an outline; releasing closes it into a filled polygon. Point editing remains available.
- Added **Undo stroke** and a preview step before saving. Disconnected, crossing, or overly complex boundaries are rejected.
- Existing hotspots can switch between circle and polygon without creating a duplicate. Use **Edit selected**, choose the shape, adjust it, then **Save draft**.
- **Level 2 GMs** can use every Hotspot control, including creating, painting, merging, and managing rotations. **Permanent deletion requires Level 3.**

Open **Drawing tools** in the Hotspot manager to choose a drawing mode. Changes stay in the draft until **Save draft**.
