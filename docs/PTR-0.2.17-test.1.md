# PTR 0.2.17-test.1 — Grappling Hook

- **Grappling Hook is now available at level 28** in Hero Advancement for Rogue Class+, Hybrid with Rogue, and Hero. It costs **3 Ability Points and 2 Legendary rarity gems**. Classic remains unchanged.
- Grapple to a ground location up to **30 yards** away, with a **35-second cooldown**.
- For **3 seconds**, the same action button offers a follow-up: grapple toward an enemy within **10 yards** and root them for **1 second**. The ability is designed to preserve stealth.
- Includes the tested smaller chain, improved endpoint tracking and cleanup, and a lowered initial ground anchor. Follow-up path checks were adjusted to avoid rejecting ordinary short paths.
- Existing Battle Pass rewards, rune recovery, creature texture fixes and other PTR updates are retained.

**Update:** Close WoW → open launcher **0.3.1 or newer** → **Check / Repair → Update PTR → Play**. No new launcher ZIP is needed for players already on 0.3.1. The server changes are already active.

Please report any remaining hook visual, terrain/pathing, stealth or follow-up issues. PTR only; Main is unchanged.
