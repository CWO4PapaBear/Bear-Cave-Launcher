# The Bear Cave PTR - 0.2.0-test.1

## Launcher updates are available
Choose your dedicated PTR client folder, close WoW, select Check / Repair, then Update PTR. The launcher verifies downloads and backs up replaced files. Play uses your existing realm address.

## Included
- Hero Advancement and persistent custom-mode enrollment, ability/talent purchasing and progression.
- Hybrid spellbook grouping and corrected onboarding prompts.
- Integrated player resource and active pet frames, including texture fixes.
- More Minions companion controls.
- Both current Patch-Z files and PTR-only Adaptive Auto Attack.

## Please test
Check player/pet frames, secondary companion status and controls, Hybrid spellbook tabs, and ability/talent purchases after updating. Report the character mode, level and exact error with any issue.

Main Server is unchanged. Settings and unrelated addons are preserved. Experimental class-identity and obsolete starting-gate diagnostic addons are not distributed. Personal layout overrides are not loaded by this package. No manual class-label cache refresh is required.

This client snapshot matches the recorded PTR server activation in the manifest. The publisher could not independently refresh live server status through WSL at publication. This is a PTR test release; in-game acceptance remains part of testing.
