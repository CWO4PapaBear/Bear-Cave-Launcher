# 🐾 The Bear Cave PTR — 0.2.3-test.1

**Close WoW → Open Bear Cave Launcher → Check / Repair → Update PTR → Play.**
Your existing launcher works. No new launcher executable or manual addon installation is needed.

## 🐾 More Minions: classic stables
- Imported primary companions now use the stable's original Current Pet box, stored slots, Purchase button and classic frame layout.
- Store, retrieve and purchase slots through the server's normal stable rules. **Undead and Demon stabling have been tested successfully on PTR.**
- Drag between the Current Pet box and a purchased stable slot to store, retrieve or swap. You can also select an occupied box, then click an empty destination box.
- Family-specific icons replace generic creature-type icons. Abominations use their stitched-head family icon; the same icon stays visible in current and stored slots.
- Secondary summoned companions remain separate and cannot be placed in this stable.

## 🍖 Pet happiness
- Happiness and diet indicators are hidden for non-Beast pets, including the stable and integrated pet portrait display.
- Beast happiness remains available. This also prevents the reported nil-tooltip error when hovering an Undead pet's happiness indicator.

## 🧪 Please test
- Store/retrieve Undead and Demon pets, buy slots, swap pets and confirm names, skills and purchased slots survive relogging.
- Check family icons in both current and stored boxes. Report any question-mark or incorrect family icon with the creature name.
- Confirm Beast happiness works and non-Beast happiness stays hidden.
- Elemental/Dragonkin stabling has not yet been verified in game. This update does not enable unsupported capture families.

## 🔄 Updating and cache
Close WoW completely before updating. **No cache deletion is required for this stable/icon update.** If an earlier creature-type change still appears outdated, close WoW and remove only **Cache/WDB/enUS/creaturecache.wdb** (use your locale folder if different). Keep your WTF settings; no per-character class-label refresh is required.

**PTR only; Main is unchanged.** This cumulative release retains the previous portrait, spellbook, tooltip, Hybrid equipment and client patch updates. Personal layouts, account settings and unrelated addons are preserved.
