# PTR Warrior update — September 25, 2026

Charge and Thunder Clap no longer require a Warrior stance in **Class+, Hybrid, and Hero**. This covers all three Charge ranks and all nine Thunder Clap ranks.

- **Classic remains unchanged.**
- You must still learn the ability normally.
- Rage costs, damage, range, cooldowns, and Charge's normal out-of-combat requirement are unchanged. Existing talents that separately allow Charge in combat retain their behavior.
- This removes Warrior stance requirements; it does not grant permission to cast in Bear, Cat, or other non-Warrior forms.

**Deployment:** the server patch is active on PTR. The matching client patch is installed locally for testing, but is **not yet included in the launcher release**. Testers should wait for the matching launcher announcement before testing this change. Updating or repairing now will not install the Warrior client patch.

Server compilation, activation checks, and private startup validation passed. In-game testing is still needed across the eligible modes, especially Hybrid with Warrior as the second class, Hero with a non-Warrior starting class, and Classic as the comparison.

Main Server is unchanged.
