# PTR client update 0.2.12-test.1

Close WoW, select PTR in the launcher, and choose Update before playing.

- New characters can choose Hero directly from the initial play-style menu. Classic, Class+ and Hero use circular buttons with explanatory tooltips.
- Hero uses the Hybrid-style advancement views and portraits. The class highlight follows the class being viewed. Hero can use class-restricted items from all classes; other item requirements still apply.
- Class icon and talent-background artwork now preloads gradually after entering the world, including while reading play-style choices. Loading pauses during combat. Please report any remaining first-visit delay.
- Advancement search shows a compact grid of ability and talent icons, sorted by level, with origin-class badges and hover tooltips. Search retains the current overview/class/tree filters. The search module and load-order entry are included.
- Tap Shift to toggle expanded advancement tooltip details.

Already active on PTR: Fabled Surge gains 10 seconds from qualifying XP kills while below four minutes remaining, capped at four minutes. Longer timers earned through multiple level-ups are preserved. The heirloom mana-regeneration Lua error is also repaired.

This cumulative package preserves the previous client fixes, including Warrior stance support and trinket visual suppression. No new MPQ changes in this release. Private reward-spin testing and unfinished Poisons Mastery are not included. No new launcher executable is required for this client-data update.
