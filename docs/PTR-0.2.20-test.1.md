# PTR 0.2.20-test.1 — Companion primaries and starter pets

Close WoW, open the launcher, and update PTR before playing.

- Beast, Undead, Demon, Elemental and Dragonkin tame companions now have separate primary slots. Only one can be active at a time.
- Learning a tame mastery makes a basic starter available when you do not already own a companion of that type: a wolf, zombie, imp, rock elemental or black whelp.
- Use the corresponding call or revive ability to select that companion type. Switching requires both you and your active pet to be out of combat.
- The stable menu now includes companion-type tabs. Purchased extra stable slots remain shared storage.
- Added initial Air, Earth, Fire and Water Elemental families and Black, Blue, Green and Red Whelp families with basic attacks.
- Death Knight creation no longer requires an existing level-55 character.

Existing pets are preserved. Relearning a mastery or abandoning its starter does not grant another starter.

The starter-grant repair is active on the server and the wolf summon has been verified in-game. This is a PTR testing release: broader acceptance testing remains open. Please test other starter types, switching, wounded/dead pet preservation, revive, stable storage and relogging, and report missing or duplicate pets.

No replacement launcher ZIP is required. Main Server is unchanged.
