# PTR 0.2.16-test.1 — Battle Pass dice rewards

- Dice spins replace the rewards at Battle Pass levels **4, 8, 12, 16, 20, 24 and 28**.
- Already claimed those levels? Keep your original rewards and receive **one new spin at each replaced level**. Open Battle Pass to claim them.
- Each spin awards one item: **Rune of Retreat 35%**, **Rune of Return 35%**, **Inherited Mark 25%**, or **Legacy Mount Token 5%**.
- The floating dice animation reveals your prize, holds it for five seconds, then sends it toward your bags. The item is delivered after that animation step.
- **Claim All** runs spins one at a time. If your bags are full or you disconnect, claim again to resume the same saved prize. Repeated requests do not create extra rewards.
- The server integration is active and the owner's Battle Pass test is complete. Current rune-recovery, texture and addon fixes are retained.

**Update:** Close WoW → reopen launcher **0.3.1** → **Check / Repair → Update PTR**. Launcher 0.3.0 updates itself on reopening; older launchers without self-update need the current privately distributed ZIP. The updated Battle Pass addon is required to claim dice rewards.

No new launcher ZIP or server restart is needed for testers already using launcher 0.3.1.
