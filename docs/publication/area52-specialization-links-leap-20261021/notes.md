# Area 52 specialization associations and Demonic Leap

- Equipment Set and Mystic Enchant preset selections now save to each unlocked specialization and return after login. Clearing a link is also saved. Each specialization keeps its own choices.
- The existing client uses these links when switching specialization. Existing equipment sets, enchant presets, collections and inactive builds are preserved. Links do not bypass normal equipment or enchant activation restrictions.

- Demonic Leap now removes its demonic wings visual when the player lands, including landing in water, instead of leaving it visible for the remainder of its five-second duration.
- Airborne movement does not remove the wings. Leap movement, reactivation and cooldown behavior remain unchanged; the existing timeout remains a fallback.
- The change is restricted to Area 52. Existing blessing, Prestige, specialization and other deployed corrections are preserved.
- Server-only correction; no client download, DLL, database or certification-label change.

Offline native build/unit, source checks, landing/recast regression and patch apply/rollback checks passed. Rendered animation confirmation belongs to live testers.
