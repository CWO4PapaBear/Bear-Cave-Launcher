**Bear Cave Launcher 0.3.10**

Fixes a stale Area 52 creature-cache record that can prevent Tab targeting Rumbling Earth-Heart elementals. Before launching the game, the launcher removes only that confirmed incorrect record so the server can refresh it. Other cached creatures are preserved; there is no full-cache clear. A local backup is retained.

Existing launcher fixes, quick file verification and connection settings are preserved. No server restart is required.

**Fully close and reopen the launcher to receive the update, then press Play.** This is a launcher update; it does not change ability verification or certification status.
