# The Bear Cave - Updates

First Character Test Boost is an account-bound, single-use item that raises an eligible Area 52 character below level 60 to level 60. It uses a rocket icon and adds no equipment, gold or riding.

Each account receives one. New recipients get a separate boost mail alongside their first level-10 Conquest of Azeroth Elite Warchest. Accounts that already received the Warchest before this update get the boost on their next newly created level-1 character. Existing level-1 characters do not trigger the catch-up gift. The Warchest and its contents are unchanged.

Boost use requires being alive, out of combat and not in flight. The item remains if the level change is refused. Testing administrators can independently disable new deliveries or item use. Prior realm fixes and verification/certification labels are unchanged.
