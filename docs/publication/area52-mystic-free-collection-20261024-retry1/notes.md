# Free Mystic Enchant collection learning and UI refresh correction

Adding a newly discovered Mystic Enchant to your collection is now free at every supported rarity. The source scroll is consumed, but no Runes of Descension or Mystic Extracts are consumed. Normal altar and eligibility requirements still apply.

Applying a learned enchant retains the same rarity-based price regardless of when you learned it: Uncommon 500, Rare 1,000, Epic 2,500 and Legendary 5,000 runes. The existing gold fallback is unchanged. Removing an applied enchant remains free.

Fix the recursive UI refresh that could cause a C stack overflow while managing Mystic Enchants. No verification labels or Certified records change. Close the game, update through the launcher after publication, then log in again to receive the new server cost configuration.
