# The Bear Cave - Updates

## Featured Draft archetypes and internal build sharing

- Build Architect imports now select an internal build or accept a portable Build Code. Existing builds have Copy Build and Copy Build Code controls; copying preserves the original.
- GMs can save DRAFT BUILD (Featured) copies and select their character-creation archetype from a grouped dropdown. The server registers the exact build revision to that archetype. One build per archetype is enforced.
- Newly created characters activate the registered Featured Draft with automatic ability and talent learning. Their listed Mystic Enchants equip immediately. Unmet ability or talent prerequisites keep the associated effects dormant until those prerequisites are learned.
- Switching between Featured Drafts before level 10 changes the eventual rewards without forfeiting eligibility. Switching at level 10 or later forfeits those rewards. Customizing the build or leaving it for an ordinary build forfeits rewards and automatic enchant grants; returning does not restore either entitlement.
- Leaving or customizing a Draft removes all currently equipped Mystic Enchants. Enchants already owned in the collection remain owned.
- Eligible characters who reach the realm maximum level receive their pinned Draft's Mystic Enchants in the collection once.
- Character-creation activation retains its pending selection until the server acknowledges success and retries temporary loading delays.

GMs must register each Featured Draft before that archetype can activate on character creation. No personal build is automatically promoted. Existing bots and their assigned builds are preserved. No Verification or Certification labels change.
