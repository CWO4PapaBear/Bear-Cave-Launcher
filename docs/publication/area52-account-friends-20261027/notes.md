# Area 52 account-wide friends

- Your characters share one friends list. Adding or removing a friend applies across your account.
- A friend remains connected to their account when they switch characters. Their currently online character appears in the list.
- The existing client displays the originally added character name in the smaller Added as line when it differs from the displayed name. Editable labels are reserved for a later update.
- Existing character friendships are combined into account friendships without duplicate entries. Existing friend notes are preserved; future note edits follow the account relationship.
- Ignore lists remain character-specific. Existing visibility restrictions and cross-faction permissions are preserved.

No client download is required. No ability, talent, Mystic Enchant or certification labels change. The current cross-faction realm fixes remain included; the separate bot work is not part of this package.

Engineering checks cover native build/unit tests, source checks, account sharing and character transitions, metadata packet format, visibility, notes, removal/relogin, database failure handling, and production-schema migration apply/retry/rollback. Live gameplay acceptance remains with testers.
