# XP Hotspot map controls, consolidation and rotation filter

Closing the XP Hotspot menu now returns the map to active hotspots only. Saved draft work remains available when editing resumes. The Delete selected confirmation is now visible on the fullscreen map and keeps its explicit confirmation requirement.

General Settings adds **Full-zone hotspots only**. It defaults off. Turning it on stops active circle/polygon/combined hotspots and limits rotation to whole-zone hotspots; turning it off restores normal eligibility without changing saved enabled flags.

The consolidation replaces 4,844 overlapping circle/polygon entries with 1,415 replacement hotspots, reducing the list by 3,429. Qualifying overlap covers at least 50% of either area. Large groups are split by zone and the existing eight-boundary limit. Each replacement is one saved list entry; the original source entries are deleted. Complete original geometry is retained inside each replacement, with no trimming. The 414 whole-zone entries and previously retired rows are unchanged.

Merged entries use the existing defaults: +150% XP, 60-minute duration, 60-minute cooldown, weight 1. A replacement remains enabled if any source was enabled; fully disabled groups stay disabled. Replacement events start inactive and enter the normal rotation. Use the launcher before playing to receive the updated controls. Prior talent, Primary Stat, Duality and SHIFT fixes are preserved. Certified records and verification totals are unchanged.
