# Prestigious Cache level requirement

Prestigious Cache item tooltips now show the realm maximum level (currently80 on Area52) instead of the item's original expansion requirement. Existing cache reward rules remain unchanged.

If a tooltip still shows the old level, close Ascension and refresh itemcache.wdb in Cache/WDB/enUS and Cache/WDB/enUS/Area 52 - Free-Pick, then reopen the client. The owner activation package backs up and refreshes these two local cache files automatically. No client addon, DLL or managed client asset is changed.
