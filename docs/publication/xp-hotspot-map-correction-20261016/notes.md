# XP Hotspot outdoor-zone selection repaired

XP Hotspot drafts can now resolve the selected outdoor zone correctly, including Durotar, the Barrens and Mulgore. The server previously confused zone IDs with exploration flags and rejected valid locations as not outdoors.

The same correction fixes whole-zone eligibility and faction-quota classification. Instance maps, subareas and invalid coordinates remain rejected.

This server-only repair passed compilation and focused offline checks. No client download is needed. Existing Mage talent corrections and White Walker work are preserved. Verification and certification totals are unchanged by this repair.
