# Featured Vanity Wardrobe Editor

- Featured Vanity Rewards now uses compact equipment icons around a centered character preview, with separate mount slots.
- Hover an icon to see its item tooltip and reward level. Left-click selects a replacement; right-click clears the slot.
- Linked Featured builds import their archetype's existing Wardrobe item set and assigned mounts into empty slots. Save the build to retain the assignments. Missing mounts remain empty.
- Saved custom items are retained. Cleared slots stay cleared after save/reopen. Load archetype set restores the original assignments; the full armor set picker remains available.

No ability, talent or Mystic Enchant verification/certification totals change.
