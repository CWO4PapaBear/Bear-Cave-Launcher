# Soul Link repair

- Corrects Demonic Embrace reducing Soul Link damage transfer to zero. Soul Link transfers 6% without the talent and 8%/10%/12% at ranks 1/2/3.
- An active Soul Link is restored with the same eligible saved demon after login. Its damage amount is recalculated from the current talent rank.
- Cancelling Soul Link clears its pet link; unlearning Soul Link prevents login restoration.
- Existing realm repairs and certification records are preserved. No client update is required.

Engineering checks are offline; gameplay certification remains with testers.
