# Beast whistles and Wardrobe pet filters

Using one of the 1,006 repaired Beastmaster's Whistles now tames its matching beast when your pet slot is available. Whistles that share a spell still grant the creature named on the item.

Search Wardrobe Beasts by name or ID and narrow results using the pet categories in the Filter menu. The Wooly Wendigo Set Cache has been removed from Beasts. Its five-piece armor set is still available in Armor Sets.
