- Rerolling an enchant scroll costs 50 Runes of Descension. Existing gold alternatives are unchanged.
- Added an Orgrimmar Runeforge map/minimap marker and a Runeforge directions option for Orgrimmar Grunts.
- Runeforge object template 191748 is half its previous visual size at every placement. Its decorative role is unchanged; functional Runeforge focus 190557 is unchanged.
- No verification or Certified labels changed. This update preserves the prior Mystic Enchant UI refresh repair.

Close the game and update through the Bear Cave Launcher before playing.
