# The Bear Cave - Updates

## Invocation and Mana-Forged Barrier
- While actively channeling Invocation, Mana-Forged Barrier absorbs as if mana were full and spends no mana on absorption.
- Normal mana-dependent absorption and mana costs return when the channel ends or is interrupted.
- Invocation’s existing channel duration, stun immunity, damage, threat and shared cooldown remain unchanged.

## Fire Totem Mastery cost display
- The advancement tooltip now explains the shared cost: Mastery costs 1 Ability Essence and 2 blue gems; each member totem costs 1 Ability Essence with no additional gems.
- The first Mastery-plus-totem purchase totals 2 Ability Essence and 2 blue gems. Standalone gem prices are identified as not being additional Mastery charges.
- Actual server costs are unchanged.

## Server Manager Raid Warning announcements
- The already installed Server Manager Announce selector gains server support for realm-wide Raid Warning text and sound.
- Normal chat remains the default. Operators confirm the announcement style and message before sending.

No new Verified or Certified status changes. The launcher client update contains only the scoped existing UI correction; no DLL or new addon.
