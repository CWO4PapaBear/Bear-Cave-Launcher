# Bear Cave branding

`bear-cave-logo.png` is the original user-supplied “The Bear Cave for server.png”, copied without alteration for use in this launcher. No Ascension branding is used.

The preview follows its midnight blue banners, warm gold metalwork, pale gold lettering and dark beveled edges. The logo retains its original lettering and aspect ratio; surrounding headings use a local serif font without downloading external fonts.

App icon: bear-cave-app-icon.png was generated with the built-in image tool from the owner-supplied logo. Prompt: isolate the bottom-center five-toed bear paw on a dark circular disk within a beveled gold ring; remove external points, text and ornaments; transparent outside the circle; readable at desktop icon sizes. The ICO contains 16, 24, 32, 48, 64, 128 and 256 pixel sizes. Original logo unchanged.
