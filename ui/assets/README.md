# Bear Cave branding

`bear-cave-logo.png` is the original user-supplied “The Bear Cave for server.png”, copied without alteration for use in this launcher. No Ascension branding is used.

The preview follows its midnight blue banners, warm gold metalwork, pale gold lettering and dark beveled edges. The logo retains its original lettering and aspect ratio; surrounding headings use a local serif font without downloading external fonts.
