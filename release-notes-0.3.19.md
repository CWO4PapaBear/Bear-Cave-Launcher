# Bear Cave Launcher 0.3.19

Area 52 now connects to the Cloud Tester Server by default. Existing Area 52 client-folder selections are retained; Play applies the Cloud login address after checking updates. The local Development option remains under Troubleshooting.

The realm selector is labeled Area 52 - Free Pick Alpha Test and shows online status and the human-only player count from the HTTPS Cloud status service. Bots are excluded. Status failures are shown as unavailable rather than an invented count.

Get COACore Client opens the official COACore realm page. Windows status requests use the established verified HTTPS fallback. Existing launcher backup retention, client verification, release-rollover compatibility and update recovery are preserved.

Close and reopen the existing launcher to receive this update, then select Area 52 and use Play. This launcher release does not restart the realm or publish a new game-client asset package.
